# HandLoan.ai website

Website for HandLoan.ai, a brand of Jatta M Kommerce Private Limited.

The site lives in [`frontend/`](frontend/). See [frontend/README.md](frontend/README.md) for how to edit, run, build and deploy it to Hostinger.

```bash
cd frontend
npm install
npm run dev      # local development
npm run build    # static site in frontend/dist (upload to Hostinger public_html)
```
